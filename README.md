# AasPass — Local Commerce Website

A premium React/Vite landing experience for AasPass.

## Includes
- Exact supplied AasPass logo assets
- Supplied AasPass brand animation in the site
- Interactive Three.js/WebGL neighbourhood network
- Mouse-reactive 3D node field
- GSAP scroll reveals
- Responsive mobile/tablet/desktop design
- Vendor and delivery-partner storytelling
- Accessible semantic structure and reduced-motion support

## Run locally

Requires Node.js 18+.

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```
